# Roadmap

This roadmap lists what is decided. It is not a release promise.

## Publication

The first public release is 0.1.0. It is published after the installation test passes in a real host session against the exact installed candidate, not before. Until then the package exists as a repository source and a local artifact.

## Other hosts

Claude Code and Codex each have a plugin, a marketplace and the same brake, registered per host. Integration with other coding agents is work in progress and not officially supported. Another host may discover the portable skill through its own supported mechanism; this repository will not claim the complete PMNM folder workflow until it documents and verifies one literal pointer for that host, and any guard for it needs its own tested port. Similar event names do not carry identical guarantees.

## Rules and guards

A rule or a guard is added only behind a concrete defect observed in use, with the evidence that prose alone was not enough. Guard hardness follows that evidence: block or ask. Nothing else is promised.
