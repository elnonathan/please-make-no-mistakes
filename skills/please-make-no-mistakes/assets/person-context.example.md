This example contains only relevant, explicit preferences. It is not active and must not be applied to any person automatically.

```text
owner: Example Collaborator
scope: communication preferences only
privacy: private
source: explicit statements from the owner
last verified: 2026-08-14

preferences:
  - Lead with the result or next action.
  - Use English for code and identifiers; use Spanish for explanations.

boundaries:

  - Do not store unrelated biography or sensitive information.
```
